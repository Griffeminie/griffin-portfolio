Capstone Project

Capstone

SealGuard — Secure Document Authentication System

Django 5.2 · Barangay Sto. Niño, Biñan City, Laguna

A web system for authenticating barangay-level procurement contracts under RA 9184, combining AES-256 encryption, SHA-256 fingerprinting, and LSB steganography for tamper-evident digital seals, with RSA-based verification and full audit logging.

Discussion of the Features

  • Document upload with AES-256 encryption and SHA-256 fingerprint generation
  • LSB steganography for embedding tamper-evident digital seals
  • RSA-based signature verification of sealed documents
  • Full audit logging of user and document actions
  • Slide-in PDF preview panel with client- and server-side validation
  • Dashboard with summary stat cards

Software used: Django 5.2, Python, PostgreSQL/SQLite, python-decouple

Personal Project

Paste & Annotate — Single-File Image Annotation Tool

HTML · CSS · JavaScript (zero dependencies)

A single-file, no-install tool for quickly marking up photos with circles, arrows, and labeled callouts — built to speed up garment QC feedback (paste a photo, circle the defect, label it, drop it into the report), but it works for any "here's a photo, mark the problem" workflow: product inspection, bug reports, design feedback, and more.

Key Features

  • Paste or drag-and-drop an image directly from clipboard — no upload step
  • Circle, arrow, and circle+arrow annotation tools with adjustable size, thickness, and label
  • Persistent label field, drag-to-move/resize, zoom/pan, and 90° image rotation
  • One-click PNG export · zero dependencies, zero build step — it's one HTML file

Software used: Vanilla HTML, CSS, JavaScript — no frameworks or build tools
